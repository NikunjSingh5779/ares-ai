# ARES AI — Landing Page

The public-facing marketing page for ARES AI, built with Astro. Minimal tech,
dark-theme aesthetic — see `docs/design.md` for the visual identity system this
page follows.

## Development

```sh
npm install
npm run dev       # http://localhost:4321
```

## Build

```sh
npm run build     # outputs to ./dist/
npm run preview   # preview the production build locally
```

Static content lives in `src/pages/`; shared components in `src/components/`.
Static assets (images, fonts) go in `public/`.

See the root `README.md` for how this fits into the full ARES AI stack.
